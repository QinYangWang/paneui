# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be constructive, and make it easy for others to help you.
Critique the work, not the person, and assume good intent.

Instances of unacceptable behaviour may be reported privately to the repository
maintainers through GitHub (a direct message or a private report on the
maintainer's profile). Reports are handled confidentially.

Project maintainers are responsible for clarifying these standards and may
remove, edit or reject comments, commits, issues and pull requests that do not
align with them.
