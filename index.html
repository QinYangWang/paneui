paneui

Interfaces, one pane at a time.

React components that feel at home on the desktop.

Get startedComponents
$npx paneui init

Principles

Concentric radius

Every corner derives from one radius, so nested parts stay aligned.

Native desktop density

Sizes and spacing are tuned for dense app screens, not marketing pages.

You own the code

Each item installs into your project as source, ready to change.

Installation

01

Register the namespace

Point your project at this registry once.

$npx paneui init
02

Install the theme

Adds the colour tokens to your stylesheet.

$npx paneui add @paneui/theme
03

Add components

Copies any item into your codebase as source.

$npx paneui add button
