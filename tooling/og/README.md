# PaneUI share image

Run `node tooling/og/render.mjs` from the repository root to regenerate the 1200 × 630 image.
Set `PLAYWRIGHT_PATH` and `CHROMIUM_PATH` if the browser tools live elsewhere.

The HTML uses the landing cloud asset and retains the pinwheel mark and `paneui.dev`.
Open it with a dark system theme to preview the navy treatment; the published PNG uses light mode.
