Table Async

Loads table rows page by page as the reader scrolls.

@paneui/theme@paneui/icons@paneui/table@paneui/button@tanstack/react-virtualmotion@base-ui/react
Event log · connecting…
Loading rows

Installation

$pnpm dlx shadcn@latest add @paneui/table-async

Usage

import { AsyncTable } from "@/components/ui/table-async"
<AsyncTable
  aria-label="Events"
  columns={columns}
  loadPage={async (page, signal) => {
    const res = await fetch(`/api/events?page=${page}`, { signal })
    return res.json() // { rows, hasMore }
  }}
/>

Examples

Error and Retry

Use when the source can fail mid-list; page 3 fails once here, so scroll down.

Reset Key and End Message

useAsyncPages

Use for paged lists that are not a table.

Errors

When loadPage rejects, a retry band replaces the footer, or a “Try again” empty state shows if nothing has loaded yet.

Accessibility

The table sets aria-busy while a page loads; the loading band is a status and the error bands are alerts.

Related

Built on Table. See also Table Editable.

API Reference

AsyncTable

Table that loads page by page as the list nears its end. Takes every Table prop except data, loading, onEndReached and footer. Also accepts every prop of Table.

(page: number, signal: AbortSignal) => Promise<AsyncPage<T>>
Fetch one page; reject to show the retry footer. Honour signal to cancel.
resetKey
unknown
Change to drop loaded pages, abort the in-flight request and start again from the top (e.g. a new filter).
endMessage
ReactNode | ((count: number) => ReactNode)
Replaces the end-of-list note shown once every page is in. Pass null to hide.
onStatusChange

Called when the load status or row count changes.
