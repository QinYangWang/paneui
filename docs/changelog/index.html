Changelog

Updates to paneui.

October 19, 2026Components

Share images for Next.js routes

October 19, 2026 · Components

  • OG Image renders straight from an opengraph-image.tsx route with ImageResponse. It exports ogImageSize and ogImageContentType for the route's size and contentType, and has a new look: title at the bottom, an optional URL, a faint grid or dot backdrop and an accent glow.
  • @paneui/og-image-route adds app/opengraph-image.tsx and app/twitter-image.tsx; @paneui/og-image-post-route adds a per-post image under app/blog/[slug]. The docs site draws its own share image the same way and writes it to /og.png, so static hosts serve it as an image; the OG Image notes show how.
  • New: OgCoverArt, the Cover Art compositions drawn for share images. A slug picks the same art in both. The file now installs as a ui component, at components/ui/og-image.tsx.
October 19, 2026Components

Sidebar-first App Shell, one border colour

October 19, 2026 · Components

  • App Shell leads with a full-height sidebar: a team switcher (AppShellSwitcher) on top, folding groups, projects and the user menu at the foot, and the panel's own header (AppShellInsetHeader) with the trigger, a divider and a breadcrumb. Add AppShellHeader for the header-first layout, now its own example.
  • The sidebar's edge line no longer runs past the inset panel's rounded corners, and the floating rail's icons sit on the trigger's column again (they were 3px off). The panel header's divider is centred.
  • Outline buttons, cards, select and combobox triggers, fields, tab lists and dividers share one edge colour, --border (gray a4) at 1px, in light and dark. --input now equals it.
  • Edited Files Card: Undo, Review and the toggle follow the card's corner, and so does a closed last file row.
October 19, 2026Components

Vendor logos in the model picker, sparkline gaps

October 19, 2026 · Components

  • Model Picker: model and effort rows show the name only. A description still type-checks and shows with showDescriptions. The examples and the agent templates show each model's vendor logo; OpenAI and xAI marks ship in lib/brand-marks.ts with Brand Icon.
  • Sparkline takes missing points (null). gap bridges them with a faint dashed line (default), breaks the line or plots zero. An empty or one-point series draws a flat dashed baseline. The line no longer breaks into dashes when the chart is stretched.
  • Removed: 404 Terminal. The SaaS template's 404 page uses Empty State.
October 18, 2026Components

iOS Zoom Lock

October 18, 2026 · Components

  • New: iOS Zoom Lock. Mount it once and iOS stops zooming into a focused field, while pinch zoom keeps working. It's opt-in; nothing mounts it for you.
  • The Input and Textarea notes now recommend it for phone forms. max-md:text-base still works when you'd rather have 16px text on phones.
October 18, 2026Components

Phone fixes for fields, the outline and the arrow button

October 18, 2026 · Components

  • Input, Textarea, Input Group, Combobox, Command, Multi Select and Native Select keep the control text size on phones too; they no longer step up to 16px under 768px. Add max-md:text-base to a field where the browser's focus zoom matters more than density.
  • Outline no longer flickers between sections while the page scrolls. A heading has to be clearly past the line before the section changes, and a clicked entry holds while the page scrolls to it.
  • The shadow swatches on Theme and the accent role strip on Customize keep every label whole and centred on a phone.
October 18, 2026Components

App shell layouts and smaller fixes

October 18, 2026 · Components

  • App Shell takes layout: inset (the default, unchanged), sidebar for a flush shell with hairlines, and floating for a rail on its own panel. Leave out AppShellSidebar for a header-only shell.
  • Accordion icon chips follow the row's corner instead of sitting round inside it.
  • Agent Code Block wrap now wraps long lines; before, the block still scrolled sideways.
  • The SaaS dashboard header shows the workspace mark beside its name.
October 18, 2026Icons

Icon stroke that matches the text, and filled nav icons

October 18, 2026 · Icons

  • Icons take weight="bold" for a 20% heavier stroke, or sit inside icon-bold. Badges, card, dialog, drawer and popover titles, page headers, empty states and settings sections use it so icons match semibold text. Buttons keep the regular stroke. Reinstall @paneui/theme for the utility; the upgrade check warns when it is missing.
  • Home, Inbox, Chat, Calendar Days, Bell, User, Settings and Folder have filled versions in every icon style. Tab Bar items take activeIcon to show one on the current tab.
  • The design skill adds rules 41–43 (stroke weight, filled active glyphs, logical text alignment) and three checks: icon-weight, nav-active-icon and text-align-logical.
October 18, 2026Components

Start and end alignment, and more translated labels

October 18, 2026 · Components

  • Text aligned left or right now aligns to the start or end, so it flips in right-to-left. In Table, align="left" and "right" map to start and end.
  • Editable Table column menus say Insert before and Insert after, and the insert marker sits on the correct side in right-to-left.
  • Tool approval, edited files, file diff, AI sidebar, colour picker, chart and pagination summary labels come from the locale provider, in English and Simplified Chinese.
October 17, 2026Components

Icons that point the right way in right-to-left

October 17, 2026 · Components

  • Arrows, chevrons, send, undo, external-link and log-out icons flip in right-to-left across components, blocks, templates and examples. Disclosure chevrons still turn down when open.
  • Carousel dots sit further apart so each one is a full 24px target.
  • The upgrade check warns when your theme is missing media-outline. Reinstall @paneui/theme to fix it.
October 17, 2026Design skill

Polish rules, checks and examples in the design skill

October 17, 2026 · Design skill

  • The design skill has eight new rules (33–40) for the details that make a screen feel finished, from target sizes to icon swaps and exits. Each comes with a Recommended and Avoid pair, shipped with the skill in examples/.
  • The check gains 21 rules (run --list) and --self-test, which runs the examples. scripts/polish-probe.js checks hit areas, image edges, heading wrap and live numbers on the rendered page.
  • The theme adds media-outline. Reinstall @paneui/theme to get it.
  • Checkbox and radio reach a 24px target; carousel dots, tab and chip close buttons extend theirs without overlapping. Button trims 2px on the icon side at every size, using start and end padding so it holds in right-to-left.
  • Icon swaps in the copy button, password reveal, theme toggle, overflow actions, status marks and slide action share one cross-fade, and springs that bounced now settle once.
October 17, 2026Components

Whole descenders and default labels that stay

October 17, 2026 · Components

  • OG Image titles and descriptions no longer cut off the bottom of g, y and p on their last line.
  • Passing aria-label={undefined} (or title, aria-labelledby) to a component keeps its default or translated label instead of removing it. A label you pass still wins.
October 17, 2026Components

Share cards, fitting tables and more translated labels

October 17, 2026 · Components

  • OG Image is a 1200 × 630 share card you render to PNG at build time. Its colours come from OG_IMAGE_TOKENS, generated from the theme for every accent in both modes.
  • Simple Table body cells keep their minimum width only on small screens, so short tables with many columns fit a reading column on desktop; empty cells never get one. cellMinWidth keeps the floor everywhere or removes it.
  • The outline, sidebar nav, command palette, theme toggle and cover art read their built-in text from Locale Provider, in English and Simplified Chinese. Their props still win, and SidebarNavSection takes a toggleLabel.
October 17, 2026Components

Table overflow, group icons and stable installs

October 17, 2026 · Components

  • Inline code in Simple Table no longer breaks inside a word, and body text keeps a minimum width, so a narrow table scrolls sideways instead of squeezing its columns.
  • SidebarNavSection takes an icon. When rows or group labels beside each other mix icons and none, the ones without start at the icon rows' text, and so do the rows inside those groups.
  • TabBarItem draws its focus ring around the icon pill and has no corners of its own, so it sits cleanly inside a rounded screen. The jump-to-latest button in MessageScroller and an expanded ExpandableControl hover to the accent's own hover colour.
  • Reinstalling items now writes the same files every time, in projects with or without Server Components: shipped files keep "use client" where they use client APIs, and files that don't, such as Label, Separator and Timeline, no longer have it.
  • The upgrade check with --fix checks again after fixing and lists only what is left.
October 17, 2026Components

Cover seeds, linked nav groups and Markdown tables

October 17, 2026 · Components

  • Cover Art has eight compositions, and a seed now also sets a mirror, a tone offset and a pattern, so posts next to each other no longer share a cover. Seeded covers change once; variant 0 to 3 look as before. coverArtStyle(seed) returns everything a seed decides.
  • SidebarNavLink takes an icon. A SidebarNavSection label can be a link to the section's own page with href or labelRender, marked current with active; the chevron beside it still folds the rows.
  • SimpleTableHead and SimpleTableCell take the align values Markdown writes: left, center and right map to the start edge, the center and the end edge. Bare code in body cells gets the inline-code chip, so MDX tables map straight onto them.
  • The Outline divider above Back to top now fades in with the link instead of showing on its own.
  • ThreadListItem with actions sends className, id, style and data-* to the list item and the rest to the row button, and takes buttonProps. SettingsRowLink takes every anchor attribute, adds rel="noopener noreferrer" to target="_blank" links and shows an external icon with external.
  • Read-only checkboxes, such as task items in ResponseMarkdown, no longer show a pointer. The menu and command shortcuts no longer trip the design check in your project.
  • Theme 2.3: reinstalling the theme leaves your stylesheet unchanged, because it no longer ships @property rules. Run the upgrade check with --fix once to delete the old copies. The design skill and the upgrade check now land at the project root in projects with src/; move an earlier src/.agents copy up, or delete it and reinstall.

October 16, 2026Docs

Docs pages you can copy, share and follow

October 16, 2026 · Docs

October 16, 2026Docs

A design skill for coding agents

October 16, 2026 · Docs

  • The design skill collects the library's rules in one place, each with a recommended and an avoid example. Install it with npx skills add QinYangWang/ui --skill paneui-design or as the design-skill registry item.
  • It ships a check that runs without dependencies and reports broken rules before you commit, plus a console snippet for nested corners as rendered.

October 16, 2026Theme

Radius stops at 16px

October 16, 2026 · Theme

  • Theme 2.2: no radius token goes past 16px, and the custom radius on Customize goes up to 1rem. Above that, controls turned into pills and nested parts drifted off their containers. rounded-4xl and rounded-5xl stay as names at the cap.
  • Multi-select chips line up with the field's corners at every radius; they were 2px too square. Message bubbles, the bottom sheet and the card folder follow the same cap.
  • The docs and blog templates show code with Code Block instead of highlighting it in the browser, and the SaaS customer drawer uses settings rows for its details and invoices.

October 16, 2026Theme

New foundation: Inter, alpha greys, four shadows and a tighter radius

October 16, 2026 · Theme

  • UI text is set in Inter with a Chinese fallback, code in JetBrains Mono and reading prose in Newsreader. Install fonts to self-host them; without it the theme uses system fonts.
